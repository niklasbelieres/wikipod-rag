\chapter*{Abstract}
WikiPod untersucht den lokalen Zugriff auf ausgewählte Inhalte der
englischsprachigen Wikipedia ohne Internetverbindung auf einem Raspberry Pi~5
mit 16~GB Arbeitsspeicher. Dafür wurde eine Pipeline entwickelt, die Artikel
aus einer lokalen ZIM-Datei anhand von Metadaten und Verlinkungssignalen unter
einem vorgegebenen Speicherbudget auswählt. Die ausgewählten Texte werden
abschnittsweise zerlegt, mit einem Embedding-Modell in dichte Vektoren
überführt und in OpenSearch indexiert. Zu natürlichsprachlichen Anfragen
abgerufene Textpassagen dienen einem lokalen Sprachmodell als Kontext für
die Antwortgenerierung mittels Retrieval-Augmented Generation. Die aufwendige
Indexierung des großen Korpus erfolgt auf einem Server; der fertige Index
wird anschließend auf die Zielhardware übertragen.

Im produktiven Selektionslauf wurden rund 1,64 Millionen von 7,32 Millionen
Kandidatenartikeln ausgewählt. Auf einem kleinen Evaluationskorpus
(194 Artikel) erreichte das Retrieval für 20 reguläre Anfragen bei fünf
betrachteten Artikeln einen mittleren Recall von $1{,}000$, einen nDCG von $0{,}963$ und
einen Mean Reciprocal Rank von $0{,}950$. Auf zwölf zusätzlichen
Edge-Case-Anfragen erhöhte die Query-Normalisierung den Recall von
$0{,}833$ auf $0{,}917$. Unter drei auf dem Raspberry Pi verglichenen
Sprachmodellen erzielte Qwen2.5~1.5B~Q4 mit durchschnittlich $27{,}97$~s
die niedrigste gemessene Generierungslatenz.

Die Ergebnisse zeigen die grundsätzliche Umsetzbarkeit des lokalen Ansatzes.
Einschränkungen bestehen durch die kleinen, manuell zusammengestellten
Evaluationsdatensätze, die unausgewogenen Beiträge der Auswahlsignale und
die hohe Generierungsdauer. Die Qualität der generierten Antworten wurde
im Modellvergleich nicht quantitativ bewertet.
